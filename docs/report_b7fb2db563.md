## 断电启动步骤

1. 关闭开发板独立电源，等指示灯熄灭。
2. 摄像头、RGB屏和SD卡保持连接。当前固件初始化仍需要OV5640，照片不来自摄像头。
3. 将底板`BOOT_CFG`的1、2两位均拨为 **OFF/OFF**，即远离开关`ON`字样的一端。依据V3.9底板原理图第2页BOOT OPTION表；JTAG对应ON/ON。仅在断电时切换。
4. 为验证独立启动，可在断电时拔开JTAG下载器与板卡的连接，然后打开独立电源。
5. 等待约60秒。预期自动显示固定夜间道路图：左原图、右增强，两侧有汽车框。它不是摄像头实时画面，移动手掌不会改变这张图。
6. 成功后再关电、重新开机一次，确认可以重复独立启动。此过程不运行任何电脑下载脚本。

## 继续使用电脑上传照片

SD启动不依赖电脑。若要处理新照片，需要接好JTAG到电脑，打开上一级“启动图片处理.cmd”，选择照片并点击处理。入口可复用SD启动的ABI30程序；图像实际输出仍为400×240。启动时正在处理示例图，会先等待上一张处理完，避免覆盖。

电脑传输方式目前是JTAG；独立SD启动并不意味着拔掉下载器后仍能向电脑传图。SD启动文件无需修改即可继续处理多张电脑照片。板卡内置启动照片只作系统展示，本轮没有新增准确率评估或增强改善识别的结论。

若未显示，先记录黑屏、停留画面或指示灯状态，不要格式化。电脑保留原始旧启动程序和新启动包，可通过下载器恢复。
